Why trust this with your key?

Don't take our word for it - every claim below is something you can check yourself.

  • Nothing leaves your browser except the one call to Google. Your key, and whatever you circle and say, goes straight from this extension to Google's Gemini API (generativelanguage.googleapis.com) - never through a server of ours, because there isn't one. Open DevTools → Network tab while it's generating and that's the only request you'll see leave the machine.
  • Zero analytics, zero telemetry. There's no tracking code anywhere in this extension - it doesn't know who uses it, how often, or for what.
  • It's open source. The entire path your key travels is three short files: options.ts (saves it), background.ts (reads it, never logs it), and generate.ts (the only place it's actually used). No other file in the extension even knows it exists. Full source on GitHub.
  • Minimal permissions, and here's why each one exists:
    • activeTab + running on the page you're looking at - needed so circle-select can see and grab what you drag a box around, on whatever site you're actually using it on.
    • storage - to remember your API key locally between sessions. That's all it's used for.
    That's the complete list - nothing about reading your history, your other tabs, or anything you're not actively circling.

1. Add your Gemini API key

Generation runs entirely from your browser using your own key - it's stored only in this browser (chrome.storage.local), never synced anywhere, and sent only directly to Google's API when generating, never to a server of ours. Get a free one at aistudio.google.com - consider creating one dedicated to this extension rather than reusing one from elsewhere, so you can revoke just this one if you ever need to.

2. How to use it

  1. On any webpage, press Ctrl+Shift+E (Cmd+Shift+E on Mac) to turn on circle-select.
  2. Drag a box around whatever you want explained or visualized.
  3. Speak what you want - it starts listening automatically and sends once you pause.
  4. Once a visualization shows up, hover it and hold V to refine it by voice without re-circling.
